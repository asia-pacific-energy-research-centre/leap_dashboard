This dashboard compares LEAP balance exports, ESTO base-year balance data, and 9th edition projection data on a common ESTO balance-axis structure. It is designed for mapping audit as much as for chart review: every charted value should be traceable back to the mapping rows and comparator pairs that created it.

What this dashboard is for

Use this dashboard to inspect where LEAP balance exports agree or disagree with ESTO base-year data and 9th edition projection data after all three are placed on a common ESTO balance-axis structure.

What the lines mean

  • LEAP lines come from the mapped LEAP balance export after LEAP sector and fuel names are converted to ESTO flow/product rows.
  • ESTO lines are base-year values read directly from the ESTO balance table for the same ESTO flow/product pair.
  • 9th lines are projection values read from the 9th edition sector/fuel table using mapped 9th sector/fuel targets for the same ESTO flow/product pair.

How rows are matched

The main mapping path is LEAP-derived: active leap_combined_esto rows connect LEAP sector/fuel paths to ESTO flow/product pairs, and active leap_combined_ninth rows connect the same LEAP paths to 9th sector/fuel pairs.

Direct ESTO-to-9th canonical mappings are only a fallback for template sections that explicitly opt in. They are not the default mapping source.

Transformation charts

  • Transformation rows are split into Inputs and Outputs for display.
  • Negative transformation values are inputs and are displayed as positive magnitudes in input charts.
  • Positive transformation values are outputs and should appear in output charts.

Where to audit details

  • Use mapping_lineage_audit.csv for row-level mapping lineage at audit years.
  • Use chart_line_mapping_ledger.csv to inspect the values actually exposed to rendered charts.
  • Use mapping_status.xlsx and dashboard_comparator_pair_coverage.xlsx to inspect missing, duplicated, and fallback mappings.
  • Use docs/esto_axis_balance_dashboard_system.md for the detailed systems guide.

Note on losses and own use

Losses and own use are still a work in progress in the LEAP model. In the transformation sector, LEAP currently models only electricity transmission and distribution losses directly. Other losses and own-use lines are handled in the demand sector under Other loss and own use.

The demand-sector approach is iterative. First-pass values are estimated from the 9th edition loss and own-use series. After the relevant proxy sector has been projected, that projected activity is used as the activity proxy. Loss and own-use intensities are then calculated from historical ESTO ratios and applied to the proxy activity. These rows should therefore be read as proxy-based estimates rather than fully final transformation-sector results.
